<!-- OVERVIEW -->
## Overview

<p>Kiddo Quest is an educational game developed in **C++** using Qt Creator, designed for middle school students. This interactive game bridges the gap between traditional education and modern technology, making learning fun and accessible. </p>
<p align="right">(<a href="#readme-top">back to top</a>)</p>

<!-- FEATURES -->
## Features
- Covers **English**, **Mathematics**, and **Geography** topic.
- **Score tracking** and **time limitations** for enhanced engagement.
- Designed with **Object-Oriented Programming (OOP) principles**, including:
  - **Abstraction**: Simplified representation of subjects and concepts.
  - **Encapsulation**: Keeping game data secure and organized.
  - **Inheritance**: Reusability of common features across game elements.
  - **Polymorphism**: Dynamic interaction with different objects.<p align="right">(<a href="#readme-top">back to top</a>)</p>

<!-- INSTALLATION -->
## Installation
### Step 1: Clone the Repository
Download the project files by cloning this repository:

```bash
git clone https://github.com/your-username/kiddo-quest.git
cd kiddo-quest
```
Step 2: Prepare Assets
Ensure the assets folder (available here) is downloaded and placed directly into the project directory:
```bash
KiddoQuest/
├── assets/
│   ├── flags/
│   ├── shapes/
│   ├── words/
│   └── ...
├── src/
│   ├── main.cpp
│   ├── country.cpp
│   ├── word.cpp
│   └── ...
├── KiddoQuest.pro
└── README.md
```
Step 3: Open in Qt Creator
1. Launch Qt Creator.
2. Open the KiddoQuest.pro file.
3. Configure the project with the appropriate kit and compiler settings.
<p align="right">(<a href="#readme-top">back to top</a>)</p>

<!-- RUNNING THE GAME -->
## Running the Game
1. Open Qt Creator and load the KiddoQuest.pro file.
2. Build the project using the Build button.
3. Run the game using the Run button in Qt Creator.
4. Follow the on-screen instructions to embark on your Kiddo Quest!

<!-- Troubleshooting -->
## Troubleshooting
**Missing Assets**: Ensure the assets folder is placed in the correct location as described in the Installation section <br />
**Build Errors**: Verify that your Qt Creator is configured correctly with the required kits and compilers <br />
**Performance Issues**: Ensure your system meets the minimum requirements for running Qt applications <br />
